# HIM Framework

## Human Interaction Measurement Framework

An open framework for measuring interaction between people, software and organizations.

---

## Vision

The HIM Framework is an open initiative to establish an international standard for measuring how digital systems support human work.

Software should not only function correctly.

It should also support people.

---

## Mission

To create a common language and framework for evaluating Human Interaction within digital environments.

---

## Principles

The HIM Framework focuses on

- Human Experience
- Cognitive Load
- Workflow Efficiency
- Information Quality
- Decision Support
- Organizational Friction
- Continuous Improvement
   
---

## Open Framework

This framework is openly published.

Everyone is welcome to study it, discuss it and contribute ideas.

---

## Long-Term Goal

To become an internationally recognized framework for Human Interaction Measurement.
